# Modern UI Skills

Codex skills for creative websites and product interfaces.

## Available skill

- [creative-web-orchestrator](skills/creative-web-orchestrator/SKILL.md):
  coordinates design, React, animation, 3D and browser QA. Performance is part
  of delivery, with visual quality preserved and desktop/mobile interactions
  measured at matching quality settings.

The orchestrator discovers specialist skills and connected tools in the
consuming environment; this repository does not bundle those dependencies.
See its [capability catalog](skills/creative-web-orchestrator/references/catalog.md)
and [performance guidance](skills/creative-web-orchestrator/references/performance.md).

## Install

Install the `skills/creative-web-orchestrator` subdirectory with Codex's
`skill-installer`, or copy that directory into your configured Codex skills
directory (usually `~/.codex/skills/`).
